How to read these numbers
  • These are proxies for use, not counts of people. None of the sources identify individuals or institutions.
  • Downloads include automated installs (continuous integration, containers, bots). Mirror traffic is excluded for PyPI. Counts are better read as trends than as numbers of users.
  • Visitor-days and cloner-days are GitHub's daily unique counts added together. One person on five days counts five times, and the same person visiting several repositories counts once per repository. GitHub clone counts are inflated by automated clients and CI.
  • Data coverage differs: GitHub traffic from {{ coverage["GitHub traffic"] }}, npm downloads from {{ coverage["npm downloads"] }}, PyPI downloads from {{ coverage["PyPI downloads"] }}. Earlier periods will understate that source.
